DMVCAT Meme Gallery Assets
==========================

Downloadable community meme images live in THIS folder. The gallery on the
site (section 6.6) serves files from here at native size.

Currently shipped:
- dmv-cat-says-no.svg     — "DMV CAT SAYS NO" rejection stamp
- now-serving.svg         — "Now Serving A-047" counter display
- sir-this-is-a-dmv.svg   — "Sir, this is a DMV" crossover reaction

How to add a meme (no CMS, content update only — PRD 6.6):
1. Add the image file here, e.g.  my-meme.png
2. Open dmvcat.html and find the MEME GALLERY section.
3. Duplicate one of the <figure class="meme-card"> blocks and point
   src + the download link at your new file.

Recommended:
- Compress images (target < 300 KB each). No 5MB PNGs (PRD 7: Performance).
- Use descriptive alt text for accessibility.
- Accepted formats: .png, .jpg, .webp, .svg

Do NOT add a user-upload form. New assets are added by the team only.
